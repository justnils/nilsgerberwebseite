# nilsgerberwebseite

Personal website of Nils Gerber

## Author

**Nils Gerber**
- GitHub: [@justnils](https://github.com/justnils)

## Tech Stack

- Nuxt 3
- Vue 3
- Bootstrap 5
- TypeScript

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is deployed on Vercel.
